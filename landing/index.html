Features

Your whole build loop, in one window.

Stop juggling a chat app, a terminal, a git client, and an editor. SuperVibe wires them together so the agent can actually act on your codebase.

Agent orchestration

Projects, worktrees, and agent sessions as a tree. Spawn subagents, fork sessions, retry messages, and auto-title each thread from its first prompt.

Real code tools

Read, write, patch, search, greps, git stage/commit, and run commands — all scoped to the worktree. No more copy-pasting around a model.

Unified tabs

Chat, Diff, Output, and Terminal side by side — with ⌘1–⌘4 shortcuts — so context never leaves your flow. See exactly what changed against the session baseline.

Model freedom

Pick any provider, or switch on the fly. Curated suggestions, capability probing, context-window awareness, and live provider health before you commit.

Granular permissions

Decide exactly what the agent may touch — file writes, commands, network, commits — with ask, session, always, or deny policies per tool.

Local-first, private

Your code stays on your machine. Works offline, syncs nowhere by default, and only hits the network for the checks you authorize.

How it works

From idea to running app.

A tight loop designed for flow. Describe the change, let the agent act, review the diff, and commit — without leaving one surface.

01

Pont about it

Type what you want in plain language. Mention the repo, a file, the diff, or a URL — SuperVibe resolves context for you.

02

The agent acts

Watches live tool activity as it reads, edits, and runs. Approve or deny each step on your terms, or trust the session.

03

Review & ship

Inspect the session diff against its baseline, test in the terminal, then stage and commit. Everything is reversible.

Quick Start

Up and running in seconds.

  • 1

    Install SuperVibe

    One command scaffolds the desktop app and wires up your agent backend of choice.

  • 2

    Connect a provider

    SuperVibe probes your installed models and shows live health, capabilities, and context windows.

  • 3

    Point it at a repo

    Open a project, create a worktree, and start a session. You're building with a model that can see and change your code.
